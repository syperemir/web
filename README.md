# КЛОДОКС

Настольное приложение: чат с ИИ, агент с доступом к компьютеру, сетевой чат
для людей в одной сети, автообновление через GitHub Releases.

Как добавить свои гифки:

1. Создайте в репозитории папку `docs`.
2. Загрузите туда файлы: `preview.gif`, `themes.gif`, `lan.gif`, `setup.gif`.
3. Названия должны совпадать — тогда картинки появятся сами.

Советы: 5–10 секунд, ширина 720–1000 px, до 10 МБ на файл
(сжать можно на ezgif.com → Optimize).

## Что внутри репозитория

- `klodoks-app/` — окно приложения (WinForms + WebView2)
- `web/` — локальный сервер (Node.js) и интерфейс
- `klodoks-setup/` — установщик (собирается через `csc`, ресурсы встраиваются)
- `dist/` — готовый zip для передачи другому человеку
- `docs/` — картинки и гифки для README

## Возможности

- Чат с ИИ через OmniRoute (локальный шлюз) или свой ключ провайдера.
- Режим агента: файлы, папки, команды, установка пакетов, сборка приложений,
  открытие сайтов и программ.
- Правая панель: что делает сейчас, о чём думает, ход работы.
- Темы: тёмная, полночь, светлая, графит, океан, лес, неон, стекло.
- Эффекты фона: снег, дождь, звёзды, RGB, туман.
- Прозрачность панелей и цвет подсветки, зимнее оформление,
  секретная фраза «клод клод погода» — все стили на 24 часа.
- Сетевой чат для людей в одной локальной сети (кружок со числом участников).
- Перенос чата между ИИ через код `KLODOKS1:...`.
- Автообновление из GitHub Releases.

## Как выпустить обновление

1. Поднимите версию в `web/config.json`:

   ```json
   "version": "1.1.0",
   "updateRepo": "ваш-логин/klodoks",
   "updateUrl": ""
   ```

2. Соберите архив с папкой `web` внутри (структура как в папке установки).

3. Создайте релиз на GitHub:

   - Tag: `v1.1.0`
   - Прикрепите к релизу zip-файл (имя заканчивается на `.zip`)

4. Приложение само увидит новую версию:

   `GET /api/update/check` → `{"current":"1.0.0","latest":"1.1.0","available":true}`

5. Пользователь: Настройки → «Проверить» → «Обновить» → перезапуск.

## Как работает проверка

- Если задан `updateRepo` (`логин/репозиторий`), сервер спрашивает GitHub API:
  `https://api.github.com/repos/{updateRepo}/releases/latest`
  Берётся `tag_name` (без префикса `v`) и первый ассет с расширением `.zip`.
- Если `updateRepo` пуст, используется `updateUrl` — прямой адрес JSON-манифеста:

  ```json
  { "version": "1.1.0", "zip": "https://ссылка/klodoks-1.1.0.zip", "notes": "что нового" }
  ```

## Установка обновления

`POST /api/update/apply` с PIN: скачивает zip, распаковывает поверх папки
установки (`%LOCALAPPDATA%\Klodoks`), просит перезапустить приложение.
Обновляется веб-часть; для замены `.exe` нужен установщик.

## Перенос чата между ИИ

- В настройках: «Экспорт кода» — копирует строку `KLODOKS1:...` (base64 от JSON
  с историей сообщений). Её можно вставить в другой ИИ и попросить продолжить.
- «Импорт кода» — вставьте код из нашего приложения или сгенерированный другим
  ИИ в том же формате, и чат появится в списке с восстановленной историей.

## Установка

1. Запустите `Установщик КЛОДОКС.exe`.
2. Нажмите «Установить» — установщик сам поставит Node.js, .NET 8 и WebView2.
3. Войдите в свой аккаунт Google (бесплатно) — так Клод привязывается к вам.
4. На рабочем столе появится ярлык «КЛОДОКС».
5. PIN для режима агента: `482913`.

## Требования

Windows 10/11, Node.js (ставится установщиком), .NET 8 Desktop Runtime,
WebView2 Runtime (оба ставятся автоматически). Порт сервера: 8787.
Папка установки: `%LOCALAPPDATA%\Klodoks`.
